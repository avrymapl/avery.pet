# avery.pet

a personal site built with Next.js and Tailwind CSS v4 :3

## design

the site follows the avery.pet design system: tokens live in `src/styles/tokens.css`, the `ap-` component classes in `src/styles/ap.css` (both copied from the design system), and site-specific styles in `src/app/globals.css`. the project catalogue, update log and now note are plain data in `src/lib/projects.ts`, `src/lib/updates.ts` and `src/lib/now.ts`.
